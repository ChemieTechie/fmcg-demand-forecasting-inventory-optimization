# Data

This repository intentionally does not store the raw M5 CSV files because they are large.

Place the following files in a local `data/raw/` directory when running the project:

- `sales_train_validation.csv`
- `sales_train_evaluation.csv`
- `calendar.csv`
- `sell_prices.csv`

The project uses the public Walmart M5 retail forecasting dataset as a retail/FMCG proxy.

After downloading the data, update notebook paths if necessary and run the data-cleaning/EDA workflow.
